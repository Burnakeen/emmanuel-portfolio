# Emmanuel Lucky — Portfolio

This is my personal portfolio website. I made it as a beginner project to practice HTML and CSS.

## What's on it

- A homepage that says who I am and what I'm learning
- A section about me
- A section showing small projects/practice work
- A section listing what I know so far
- A way to contact me

## What I built it with

- **HTML** — for the structure and content
- **CSS** — for all the colors, spacing, and layout (I wrote it myself, no template)
- No frameworks or website builders — just plain code

## How to view it

Just open `index.html` in any browser — no setup needed.
